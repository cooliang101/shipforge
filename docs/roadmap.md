# ShipForge Roadmap

2026-09-07 产品方向调整：全面采用 [原目录发布](deployment-contract.md)，兼容既有程序发布方式。旧版本目录、迁移、远端多版本保留和备份管理工作包停止，不再作为后续路线。

2026-09-08 范围收敛：按个人部署助手交付，不建设企业级流水线。核心部署已可用并有实际项目验证；后续以易用性和轻量收尾为主，不再把完整故障矩阵作为交付前置条件。范围调整不表示尚未执行的测试已经通过。

## 已实现

- TUI 项目/组件/环境配置，连接管理、Host Key 确认、密码/私钥/Agent 登录。
- 本地构建与 tar.gz Release 打包、SSH/SFTP 上传校验。
- 既有 root 内应用文件发布，唯一上一版应用压缩包，已知失败恢复。
- 现有服务 argv、systemd 预设、保存密码 sudo；不修改 sudoers 或服务器配置。
- 本地历史、日志、取消、终端恢复、只读核实及有证据的恢复。
- 新驱动的临时目录测试与真实回环 SSH/SFTP 测试。见 [当前验证](validation/inplace-deployment.md)。

## 已有部署与验证

- 已用新版 ShipForge 在 aiagent 的既有 server/website 目录完成业务发布和接口检查。
- 已完成最终 release 终端冒烟，并记录实际部署结果。
- 2026-09-08 较早一轮 Windows 构建及 WSL 发布器 21 项契约/故障测试通过，覆盖部分写入、状态写入、权限拒绝、恢复失败及 SIGKILL。范围见 [WSL 异常验收](validation/wsl-inplace-faults.md)，最终构建见下方收尾记录。

## 个人使用版收尾：已完成（2026-09-08）

1. **轻量安全复核**：已复核防误删、凭据/日志、Host Key、上传校验及失败结果路径。修复状态文件损坏时透出底层解析器诊断的问题，补充真实子进程回归；未改发布/恢复规则或配置 schema。
2. **易用性与交付**：已有 TUI 输入、默认值、窄窗口与错误提示测试通过，本轮未发现需另改 UI 的具体问题。已更新固定路径 `target/release/shipforge.exe`，补齐[运行、配置复用、更新和失败处理指南](personal-use.md)，同步旧版本目录语义残留。
3. **简短验收**：复用 aiagent 实际部署记录；TUI 保存后加载配置、密码连接复用及代表性失败测试通过；修复后的本机测试、fmt、Clippy、release 构建和两个准确 exe 的 ConPTY 冒烟通过，WSL 发布器套件增至 22 项通过。修复与文档收尾分别提交。

证据、可执行文件 SHA-256 和未验证边界见[个人使用版验收](validation/personal-use.md)。当前个人使用版已完成本轮交付要求，后续按实际使用反馈迭代，不启动新的大工作包。

## 按需改进，不阻塞个人使用版

真实 systemd/PM2 服务故障、SSH 断连、客户端中断及多组件恢复的更广端到端测试，按实际问题和相关代码改动补充。现有 WSL 发布器测试不等于这些场景已验证，也不证明断电持久性；不为补满测试矩阵持续扩建环境。

不新增权限/审批、合规审计、流水线治理、锁、跨机器协调、远端助手、数据库/附件/运行数据管理或多版本备份。现有必要防护和测试不删除。

旧 M1/M2/M3 和 QA 文档保留为历史证据，不代表新原目录驱动已获得旧协议的全部真实服务器验收覆盖。
