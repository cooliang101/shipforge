## 支持范围与环境

- 客户端仅支持 Windows x64 GNU，部署目标仍是 Linux SSH 服务器。实测系统为 Windows 11（10.0.22631）、PowerShell 7.6.5 和 ConPTY；不据此承诺其他 Windows 版本、MSVC 或 Linux/macOS 客户端兼容。
- 使用既有 Rust/Cargo 1.96.1、目标 `x86_64-pc-windows-gnu` 和 MinGW GCC/ld，没有安装或升级本机或 WSL 工具。Cargo 的 Rust 1.88 声明保留，但不作为经过实测的最低版本承诺，不再要求额外工具链矩阵。
- GitHub Actions 测试工作流已移除。格式、Clippy、测试、构建、性能、SSH 和依赖审计均在本机执行；推送只同步仓库提交，不触发测试、合并或发布。命令与隔离规则见 [测试指南](../../tests/README.md)。
- 真实认证证据覆盖不同的本地 IdentityFile 与 Windows OpenSSH Agent Key，以及两个独立 Host Key；Pageant 等其他发现路径不等于已完成实机兼容验收。

## 限制与后续工作

TUI-MGT-01 的早期间歇 SSH 超时和另一次 unknown-current 仍无已证实根因。连接现有 TCP、握手/Host Key、IdentityFile、Agent 和认证阶段诊断，共享绝对总期限；后续通过只表示未复现，不表示根因已修复。远端取消在独立的一秒窗口尝试确认结果和终止 channel，无法确认仍报告中断，不能保证远端进程已经终止。

IdentityFile 限定为 1 MiB 内的本地普通文件；拒绝最终 link/reparse、特殊文件及明显 UNC/device 路径，但不能可靠识别映射盘、网络挂载或父级 junction。进程级单飞线程隔离阻塞读取；Rust 无法强杀该 OS 线程，永久阻塞时后续文件 Key 尝试可能持续超时，进程退出后恢复。

ConPTY 不提供 Unix termios 对照；只有暴露 alternate-screen 字节时才验证其成对顺序。两个 smoke 不替代全部页面的人工体验或 Break/Close/Shutdown 实机测试；性能门禁测量合成输入到 Ratatui TestBackend 帧的调度延迟，不测物理显示延迟。

QA-01 的结论是上述 Windows 条件下的候选验证通过，不是生产发行。下一工作包 `QA-02` 做专项安全审查和更新后的依赖审计；`QA-03`、`REL-03`、`ACC-01` 继续完成兼容/安装、Windows 单文件包和完整 MVP 验收。
