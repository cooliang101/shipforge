# TUI-04：管理页面一致性验收

日期：2026-09-05。状态：TUI-04 通过自动化工作包验收；实现、交叉审查、文档复核和双平台最终门禁均已完成。本记录冻结 TUI-04 证据；后续退出加固与压力门禁已由 [TUI-05](tui-05.md) 和 [TUI-06](tui-06.md) 完成，M4 和完整 MVP 仍待完成。

## 实施范围

- 管理页保留最多 8 层非递归返回快照，恢复准确 Project/Environment 范围、页码、选中项和视口。翻页替换当前列表；同页刷新按稳定 ID 保留焦点，目标消失时合理回退。
- 失败进入持久错误页，安全读取或计划检查可用 `f` 明确重试；返回旧页保留快照提示。取消的本地读取、回滚候选和计划丢弃迟到结果，库存检查与实际执行保留已知报告、结果和警告。
- 回滚候选用 `d` 查看完整目标与不可用原因；拒绝预览返回原选择。实际执行后清除旧候选、确认和重试路径，不能从结果页再次执行同一计划。
- 历史列表优先展示结果、创建时间和 pending 数，完整 ID 另行展示。详情补全已有包、回执、步骤起止、观察和意图证据；创建/更新时间不冒充执行起止，缺失或倒置耗时不制造 `0ms`。
- 检查报告顶部区分已保存与保存未确认的观察，逐条展示已有审计和临时残留。版本一致、准备回执、审计阶段成功和残留识别均不授予健康、整体成功、所有权或清理结论。
- 回滚结果以 typed state 区分成功、失败和取消，首行保留警告及人工恢复数量；主失败、补偿错误和持久化警告分开。仅精确匹配已知完整警告输出受控操作说明，不回显未知 Driver 原文。
- 证据页缓存不可变文档，返回快照共享缓存；`usize` 逻辑行视口只生成可见行列，支持 Home/End、粗细横移及 Unicode 字符簇。历史只读限制不因已有预览缓存而失效。

使用方式见 [TUI 指南](../tui-guide.md#历史release-与回滚)。没有新增 YAML 字段、存储迁移、CLI/AI 入口或锁；没有改变部署、健康、补偿、恢复及保留算法。

## 范围限制

默认测试只使用临时项目、数据库、Fake Driver、`TestBackend` 和回环协议服务器；本阶段未重复双 Destination 或 WSL systemd 实机部署。自动化 80×10 渲染不是人工终端体验。证据投影测试不等于秘密检测、完整远端清理授权或全进程资源基准。

管理库存检查只调用 `inventory`，不执行部署预检或服务健康检查。报告与旧历史均为有限时间的观察，不自动纠正远端或完成原意图。

返回缓存有层数边界，原查询仍有记录/字节上限；本记录不宣称全进程内存、有界过载或输入延迟已经验收。全部任务的退出与线程结束跟踪已由后续 [TUI-05](tui-05.md) 审计，合成吞吐门禁已由 [TUI-06](tui-06.md) 覆盖；macOS、最低 Rust 版本、发行包及早期未定位 SSH 超时归 M4。
