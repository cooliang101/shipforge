# TUI-MGT-01：管理功能验收记录

日期：2026-09-04。状态：TUI-MGT-01 已通过工作包验收，M2 范围已完成；M3/M4 与完整 MVP 尚未完成。验收依据是独立代码审查、双平台最终门禁、界面回归和下列真实服务测试，不将复跑通过视作早期间歇故障已定位修复。

最终范围审计发现的“删除 Environment 后无法浏览旧记录”缺口已补齐：新增按精确 ID 选择的只读入口，支持仅有报告的环境，并在 UI 和网关两层拒绝远端操作。五项界面回归及五项查询/存储回归已纳入双平台最终测试。损坏 `_shipforge` 的明确确认重新初始化仍缺 TUI 入口，已显式列入 M3 TUI-02；底层 API 存在不等于用户流程完成。

## 实施范围

- TUI 项目编辑：Component/Environment 草稿、重新发现、结构化构建参数、逐组件目标选择、完整 YAML 预览和显式保存。保存复核原文件、目录身份、权限及连接修订；改名按配置规范保留或新建身份。检测到外部变化则拒绝保存，不承诺与外部编辑器并发写入的原子隔离。
- 独立连接管理：选择 SSH 配置、Agent 或私钥，确认 Host Key 后认证保存；修改保留历史修订。移除前检查已登记项目及历史引用，证据缺失时拒绝；项目移除只取消最近列表登记。
- 本地历史、详情、日志和检查报告采用只读、有界查询；浏览不创建或迁移数据库，不自动连接服务器。已删除 Environment 仍可从历史 ID 列表查看，最多校验 4,096 个不同 ID，再每页显示 20 条。日志校验文件身份并脱敏、过滤终端控制字符后再次脱敏。
- 显式库存检查读取远端事实，无本地历史时也可保存库存缓存，但缓存不构成回滚授权。所选子集回滚要求原始历史包、端点修订、generation 和健康证据，执行前重新检查远端；创建关联原发布的新记录，不改写原结果。未知状态不等于未部署。
- 界面只调用应用服务；一个受跟踪后台工作任务，明确取消并等待结果或恢复边界。确认页只接受无修饰确认键，不提供后台脱离或 Agent 调用。

操作见 [TUI 指南](../tui-guide.md)；实现边界见 [架构](../architecture.md)。没有新增 YAML 形式或数据库 schema。

## 审查与默认门禁

应用服务、SQLite 查询、配置编辑、连接管理、回滚和界面相互独立审查。已修复原始 SQLite/凭据解析错误泄露、Shift 确认绕过、表单取消残留、artifact 相对路径描述和日志过滤后秘密重组等问题。回归包括真实 SQLite 触发器失败、只读文件边界、键盘操作路径及 Fake Driver 的无副作用断言。

包含连接阶段诊断及历史 Environment 入口的冻结源码最终门禁。测试命令为 `cargo test --locked --all-targets --all-features --quiet`，另执行严格 Clippy、`cargo fmt --all -- --check` 和 `cargo build --locked --release`：

连接诊断增加了同一截止时间不被重置、停滞握手不读取凭据及极端期限不 panic 三项回归。诊断 runner 的范围验证、双流排空、限时限长、失败后清理替身测试也通过；诊断工作预算不包括末尾回收辅助进程的短暂等待。

## 真实 Management 用例与发行风险

入口：`tests/run-linux-acceptance.ps1 -Suite Management`。精确运行 `management_acceptance::real_linux_management_history_rollback_and_connections`，总限时 600 秒；零匹配不算通过。

用例在两个独立 Host Key、随机回环端口、非特权 OpenSSH 容器上运行。测试先确认夹具 Marker，使用唯一部署目录和临时身份，不访问生产配置。覆盖连接创建/认证、实际端点变更及历史修订、未引用连接移除、单组件后联合发布、本地历史和真实日志、仅回滚 frontend 而保持 backend、保存检查报告并确认原部署记录未改。该用例验证应用服务和真实 Driver；键盘操作另有界面测试，不冒充人工 TUI 验收。

独立 `ConnectionStability` 排障用例在运行 `9ed8f9822ecc4ae49be79392316bf032` 中通过 100/100 次双端点交替严格连接及只读 Marker 校验，12.22 秒，runner 退出码 0 并完成清理。每轮按 Driver 的方式丢弃 session，不复用或显式 disconnect；没有远端写入或重试。它提供短序列基线，不证明无资源积累，也不替代完整 Management 验收；不包含在 `All` 中。
